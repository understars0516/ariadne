# Figures

*Journal*: nature | *span*: single | *lang*: en | *rendered*: True

**fig_distribution.pdf**

*Distributions of the continuous variables. The dashed line marks the median and n is printed in each panel; skewness is reported per panel (|skew| > 2 means symmetric summaries mislead). No uncertainty interval is shown because these are complete observed distributions, not estimates.*

Key message: which variables are skewed, bounded, or contain extreme values

**fig_group_comparison.pdf**

*post_score by arm. Each point is one observation; the box shows median and IQR, the half-violin the density, and n is printed under each group. F(3, 407) = 0.74, p = .529, η² = 0.005. Spread shown is IQR, not SEM.*

Key message: whether post_score differs across arm, distribution included

**fig_scatter_fit.pdf**

*change_score against post_score. The line is the OLS fit with a 95% confidence band for the mean; r = 0.99, p < .001, n = 411. The band describes precision of the mean, not the spread of individuals.*

Key message: form and precision of the post_score-change_score relationship

**fig_correlation_heatmap.pdf**

*Correlation matrix (Pearson r, pairwise complete; n per pair is the number of complete observations, given in the analysis table). Stars mark uncorrected p-values. No confidence interval is shown per cell, so read |r| as shared variance (r = .30 is about 9%), not as an effect size.*

Key message: which variables carry overlapping information

**fig_forest.pdf**

*Coefficients with 95% confidence intervals (n = the model sample size, in the analysis table). Intervals crossing zero (grey) are compatible with no effect; that is a statement about precision, not proof of absence.*

Key message: which predictors matter, and how precisely

**fig_panel_composite.pdf**

*Composite figure, n is printed within each panel (group sizes under panel b). (a) Distribution of the primary variable. (b) Group comparison with individual observations; the box shows median and interquartile range (not SEM) and the half-violin the density. (c) Correlation structure among the core variables. Panels share one colour scheme and the same font sizes.*

Key message: shape, difference and structure in one figure
